# php-base-images-cache

BuildKit cache and per-arch build images for [php-base-images](https://github.com/mintopia/php-base-images), published as `ghcr.io/mintopia/php-base-images-cache`. Not for consumption: use `ghcr.io/mintopia/php` and `ghcr.io/mintopia/nginx`. A daily cleanup deletes untagged and broken images older than a day, and cache tags not refreshed in 45 days.
